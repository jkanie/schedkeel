= schedkeel API
:toc: left
:toclevels: 2
:sectanchors:

Every example on this page comes from a test that ran against PostgreSQL,
Redis and Kafka. When the API changes, the build regenerates this page.

The API speaks HAL (`application/hal+json`). Start at `GET /api` and follow
links. Errors are problem details (`application/problem+json`, RFC 9457).

== Sign-in

Scripts and the CLI send HTTP Basic credentials. The dashboard posts a form
to `/api/login`, then keeps the `SESSION` cookie (stored in Redis). VIEWER may
read. ADMIN may also change.
